# AI Knowledge Handoff: AUCA Certificate Portal

## 📌 Project Overview
A professional ASP.NET Core 8 MVC application for the Adventist University of Central Africa (AUCA). The system manages student "Certificates of Good Standing," providing search, web-based high-fidelity preview, and watermark-free PDF generation.

## 🏗 Architecture & Tech Stack
- **Framework**: ASP.NET Core 8.0 (MVC)
- **Data Access**: Dapper (Parameterized queries)
- **PDF Engine**: PuppeteerSharp (Headless Chromium)
- **DOCX Engine**: DocumentFormat.OpenXml
- **QR Engine**: QRCoder
- **Logging**: Serilog (Console + Daily Rolling File)
- **Deployment**: Dockerized (Linux-based) targeted for Render.com

## 📂 Key File Structure
- `Controllers/CertificateController.cs`: Main orchestration logic. Unique routes enforced: `/Certificate/Preview/{id}`, `/Certificate/DownloadPdf/{id}`.
- `Services/CertificateService.cs`: The "Brain." Handles OpenXml (DOCX) and Puppeteer (PDF) generation. Uses **Memory-based HTML rendering** (not URL navigation) for cloud stability.
- `Repositories/CertificateRepository.cs`: Implementation of `ICertificateRepository`. Contains the `UseMockData` logic.
- `Models/CertificateRecord.cs`: Domain model mapping exactly to the SQL table `[dbo].[CertificateOfAttendance]`.
- `wwwroot/images/`: Contains `auca-logo.png` and `signature.png`.

## ⚙️ Critical Configuration (The "Switches")
1. **Mock Mode**: Controlled by `UseMockData` (bool) in `appsettings.json` or Environment Variables. 
   - `true`: Bypasses SQL Server, uses in-memory list in `CertificateRepository`.
   - `false`: Attempts real connection via `DefaultConnection`.
2. **Environment**: App is currently in `Development` mode on Render to allow debugging, but configured for `Production` hardening (HSTS, CSP, X-Frame-Options).

## 🛠 Hard-Won Bug Fixes (READ BEFORE MODIFYING)
- **PDF Timeout Fix**: Cloud servers block internal network calls and external font loading. **Fix**: Images (Logo/Signature) are converted to **Base64 strings** and embedded directly in the HTML. The generator uses `WaitUntilNavigation.Load` and `DefaultNavigationTimeout = 0`.
- **Linux Chromium Fix**: Puppeteer cannot download Chromium on restricted cloud filesystems. **Fix**: Chromium is pre-installed in the `Dockerfile`. The app points to it via `PUPPETEER_EXECUTABLE_PATH=/usr/bin/chromium`.
- **D-Bus Error**: Linux servers lack a desktop communication bus. **Fix**: Added `ENV DBUS_SESSION_BUS_ADDRESS=/dev/null` to Dockerfile and `--no-sandbox` to Puppeteer args.
- **Ambiguous Match**: "Preview" and "Download" addresses conflicted. **Fix**: Enforced explicit attribute routing in the Controller.
